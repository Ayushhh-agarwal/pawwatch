# Agent Images

Drop images here to override the drawn pet icons.

Use the agent name as the filename:

```text
Claude.png
Claude Code.png
Codex.png
Gemini.png
Aider.png
OpenCode.png
Goose.png
Cursor.png
Copilot.png
ChatGPT.png
```

PNG/JPG/HEIC/WebP are supported by macOS. Square images look best.

Do not commit third-party logos unless you have the right to redistribute them.
